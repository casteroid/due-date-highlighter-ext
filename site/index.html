Due Date Highlighter

Dates on the pages you choose, coloured by how close they are.

Install from the Chrome Web Store Source on GitHub

How it works

  1. Open the popup on a site and pick Enable on this site or Enable on this page only. Chrome asks for access to that origin only.
  2. Every date on the page gets a colour from a tier profile: Overdue Today Next 3 days This week. The Later tier is there too, switched off by default.
  3. Open the popup again to list every date on the page in order. Click one to jump to it, filter by tier, and switch formats on or off for that site.

What it does

Many formats

2026-10-25, Oct 25, 2026, 25 October 2026, 25/10/2026, Sun, 25 Oct 2026, Oct 25, and month names in Portuguese, German, French, Spanish and Italian. Optional: US month-first dates, two-digit years, and relative phrases like "tomorrow" or "next Friday".

Tiers you control

Day ranges, colours, style (background, underline, outline or badge) and a "+3d" or "3d ago" badge.

Two profiles

"Due dates" for upcoming deadlines and "Waiting time" for queues where you care how long something has been waiting. Pick a profile per site.

Popup list

Every date on the page, in order. Click one to scroll to it, filter by tier, and switch individual formats on or off for that site.

Context rules

Only highlight dates near words like "due" or "deadline", under a table column such as "Uploaded", or under a given heading. Skip dates near "created" or "posted".

Custom formats

A regular expression with named groups for anything unusual, checked against your own samples in a live tester.

Setup recipes

Each recipe starts from the defaults. Add the rule under Site rules → Add rule in the options page, or from the popup with Enable on this site, then expand the rule to set its overrides.

Teacher marking a queue

You want to see which uploads have waited longest, and nothing else on the page.

Rule
the LMS host, e.g. lms.example.edu
Profile
"Waiting time"
Context keywords
uploaded
Context parts
"Table column header" on, "Nearest heading above" on

Project manager on an issue tracker

You want deadlines in issues to stand out, not every created or updated stamp.

Rule
https://github.com/myorg/*/issues* (a URL prefix with wildcards; query and hash are ignored)
Profile
"Due dates"
Context keywords
due, deadline
Ignore keywords
created, updated, opened

One rule per tracker path keeps the rest of the host untouched.

Student on a course portal

You want every deadline in view, including the ones weeks away and the ones written as words.

Rule
the portal host, e.g. portal.example.edu
Profile
"Due dates", with its "Later" tier switched on so far-off deadlines show green
Formats
tomorrow on for that site, from the popup's "Formats on this page" or the rule's format override, so "next Friday" and "in 3 days" count

Finance or ops on a US-formatted admin table

Your admin tool writes 10/25/2026 and compact stamps like 20261025.

Rule
the admin host, e.g. admin.example.com
Formats
10/25/2026 on and 25/10/2026 off for that site; optionally 25/10/26 on for two-digit years
Ambiguous numeric dates
"Month first" on the rule
Custom formats
label yyyymmdd, pattern (?<y>\d{4})(?<m>\d{2})(?<d>\d{2})

Multilingual intranet reader

Your intranet mixes English and Portuguese, or German, French, Spanish or Italian.

Rule
the intranet host; nothing else to set
Full dates
month names in all five languages are on by default: 25 de outubro de 2026, 25. Oktober 2026, 12 out. 2026
Short dates
a short month name without a year counts only in the page's own language, read from its lang attribute: 12 out on a Portuguese page, 5 Mar on an English one

If the intranet uses one language, set "Page languages" on the rule to just that one, e.g. pt, so month names from the other languages are never read. English is always on.

Tips

  • Use Enable on this page only for one noisy URL instead of a whole host.
  • Rule patterns: example.com is that host, localhost:8080 that port, *.example.com the domain and all subdomains, https://host/path/* a URL prefix. The most specific enabled rule wins.
  • The toggles under "Formats on this page" in the popup write an override on that site's rule only.
  • Tiers are checked top to bottom and the first match wins. The options page warns about overlaps and gaps.
  • Each profile picks its badge text: "Signed: -3d / +5d" or "Ago: 3d ago / in 5d".
  • Press Rescan in the popup after a page changes without a navigation.
  • Unwrapping restores the page byte for byte, so Disable here leaves no trace.

Privacy

The extension does nothing until you turn it on for a site or a single page from the popup. It then asks Chrome for access to that site only, and releases the access when you turn it off. Page text is read in your browser and never leaves it: no accounts, no analytics, no network requests.
